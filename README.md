# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input.

## Description
This project is a command-line calculator that computes the simple interest 
for a given principal amount, rate of interest, and time period using the 
standard formula:

**Simple Interest (SI) = (P × R × T) / 100**

Where:
- **P** = Principal amount
- **R** = Rate of interest (per annum)
- **T** = Time period (in years)

## Usage
Run the script from the terminal:

```bash
./simple-interest.sh
```

You will be prompted to enter:
1. Principal amount
2. Rate of interest
3. Time period (in years)

The script will then output the calculated simple interest.
